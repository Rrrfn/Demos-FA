Markazi Text — Persian/Latin display serif
==========================================

The `markazi-arabic.woff2` and `markazi-latin.woff2` files in this directory are
the Arabic and Basic Latin subsets of **Markazi Text**, a variable-weight
serif typeface designed by Borna Izadpanah, Fiona Ross, Alice Savoie and
Gerry Leonidas.

  Source : https://fonts.google.com/specimen/Markazi+Text
  License: SIL Open Font License, Version 1.1

The Latin subset is used for the wordmark and numerals; the Arabic subset
carries the Persian display headlines through the full 400–700 weight range,
served from the single variable file per subset.

Vazirmatn
=========

`Vazirmatn-Regular.woff2`, `Vazirmatn-Bold.woff2` and `Vazirmatn-Black.woff2`
are the body/interface face, by Saber Rastikerdar.

  Source : https://github.com/rastikerdar/vazirmatn
  License: SIL Open Font License, Version 1.1

Both families permit use in commercial products, including embedding and
redistribution with the licence text retained.
