# هلدینگ آرمان — وب‌سایت شرکتی

وب‌سایت شرکتی چندصفحه‌ای برای یک هلدینگ سرمایه‌گذاری چندبخشی؛ پیاده‌سازی‌شده با **HTML5، CSS و JavaScript** — بدون فریم‌ورک، بدون فونت اینترنتی و بدون هیچ وابستگی خارجی. سایت کاملاً ایستا است و روی هر هاست استاتیک یا CDN اجرا می‌شود.

> **توجه:** این پروژه یک نمونه‌کار نمایشی است. تمام نام‌ها، آمار، اخبار و محتوای صفحات فرضی هستند و صرفاً برای نمایش ساختار و کیفیت پیاده‌سازی به کار رفته‌اند.

---

## اجرای محلی

هیچ مرحله نصب یا بیلدی لازم نیست؛ کافی است پوشه پروژه با یک سرور ایستا سرو شود:

```bash
cd 02-arman-holding
python -m http.server 8000
# سپس در مرورگر: http://localhost:8000
```

## ویژگی‌ها

- **ناوبری یکدست:** هدر چسبان، مگامنو حوزه‌های فعالیت، منوی موبایل و مشخص‌کردن صفحه فعال با `aria-current`.
- **سیستم طراحی اختصاصی:** تمام رنگ‌ها، فاصله‌ها و اندازه‌ها بر پایه متغیرهای CSS تعریف شده‌اند.
- **ریسپانسیو:** سه نقطه شکست (۱۰۲۴ / ۸۶۰ / ۶۰۰ پیکسل) بدون سرریز افقی.
- **تعاملات سبک:** نمایش تدریجی هنگام اسکرول، شمارنده اعداد با ارقام فارسی، هاور تصاویر و کارت‌ها — بدون کتابخانه جانبی.
- **فرم تماس با اعتبارسنجی:** بررسی فیلدها، نمایش خطا و حالت موفقیت.
- **دسترس‌پذیری:** ساختار معنایی HTML5، برچسب‌های ARIA برای مگامنو و فرم، و کنتراست خوانا در هر دو پوسته روشن و تیره.
- **فونت محلی:** وزیرمتن در سه وزن (۴۰۰ / ۷۰۰ / ۹۰۰) به‌صورت `woff2` داخل پروژه — بدون درخواست به سرور خارجی.

## دپلوی

خروجی پروژه صرفاً فایل‌های ایستا است، بنابراین روی Render، Netlify، Vercel، GitHub Pages یا هر هاست دیگری قابل انتشار است.

برای **Render**: یک Static Site بسازید، پوشه `02-arman-holding` را به‌عنوان ریشه (Root Directory) انتخاب کنید و دستور بیلد را خالی بگذارید؛ فایل `render.yaml` نیز همین تنظیمات را به‌صورت Blueprint در اختیار می‌گذارد.
