# هلدینگ آرمان — وب‌سایت شرکتی چندصفحه‌ای

وب‌سایت شرکتی یک هلدینگ سرمایه‌گذاری چندبخشی: هجده صفحه، شش حوزهٔ فعالیت، اخبار و مقالات، پایداری و فرصت‌های شغلی. ساخته‌شده با **HTML5، CSS3 و JavaScript خالص** — بدون فریم‌ورک، بدون مرحلهٔ Build و بدون هیچ درخواست به دامنهٔ بیرونی.

**نوع:** سایت ایستا · **پشته:** HTML5، CSS3، JavaScript · **آزمون خودکار:** ندارد

> **توجه:** این پروژه یک نمونه‌کار نمایشی است. تمام نام‌ها، آمار، اخبار و محتوای صفحات فرضی‌اند و صرفاً ساختار و کیفیت پیاده‌سازی را نشان می‌دهند.

## قابلیت‌ها

- **ناوبری یکدست:** هدر چسبان، مگامنوی حوزه‌های فعالیت، منوی موبایل و مشخص‌کردن صفحهٔ فعال با `aria-current`
- **سیستم طراحی اختصاصی:** همهٔ رنگ‌ها، فاصله‌ها و اندازه‌ها بر پایهٔ متغیرهای CSS
- **واکنش‌گرا:** سه نقطهٔ شکست (۱۰۲۴ / ۸۶۰ / ۶۰۰ پیکسل) بدون سرریز افقی
- **تعاملات سبک:** نمایش تدریجی هنگام اسکرول، شمارندهٔ اعداد با ارقام فارسی، هاور تصاویر و کارت‌ها — بدون کتابخانهٔ جانبی
- **فرم تماس با اعتبارسنجی:** بررسی فیلدها، نمایش خطا و حالت موفقیت
- **دسترس‌پذیری:** ساختار معنایی HTML5، برچسب‌های ARIA برای مگامنو و فرم، کنتراست خوانا در هر دو پوسته
- **فونت محلی:** وزیرمتن در سه وزن (۴۰۰ / ۷۰۰ / ۹۰۰) به‌صورت `woff2` داخل پروژه

## اجرای محلی

هیچ نصب یا مرحلهٔ Buildی لازم نیست؛ کافی است پوشه با یک سرور ایستا سرو شود:

```bash
cd 02-arman-holding
python -m http.server 8000
# سپس در مرورگر: http://localhost:8000
```

## استقرار روی Render

مخزن چندپروژه‌ای است؛ **`rootDir` باید تعیین شود**، وگرنه Render از ریشهٔ مخزن منتشر می‌کند.

### روش ۱ — Blueprint (پیشنهادی)

1. **New +** → **Blueprint**
2. مخزن `Demos-FA` را انتخاب کنید.
3. **Blueprint Path**: `02-arman-holding/render.yaml`
4. **Apply**.

### روش ۲ — Static Site دستی

| فیلد | مقدار |
|---|---|
| **Root Directory** | `02-arman-holding` |
| **Build Command** | خالی |
| **Publish Directory** | `.` |

خروجی صرفاً فایل ایستا است، پس روی Netlify، Vercel، GitHub Pages یا هر هاست استاتیک دیگری هم بدون تغییر منتشر می‌شود.
