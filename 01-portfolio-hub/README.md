# پورتفولیو هاب — صفحهٔ معرفی مجموعه پروژه‌ها

یک صفحهٔ تعاملی و ایستا که ده پروژهٔ مجموعه را در یک مسیر واحد معرفی می‌کند: تصویر واقعی هر برنامه، مسئله و راهکار هر پروژه، پشتهٔ فنی و پیوند کد. بدون فریم‌ورک، بدون مرحلهٔ Build و بدون هیچ کتابخانهٔ سمت‌کاربر.

**نوع:** سایت ایستا · **پشته:** HTML5، CSS3، JavaScript خالص · **آزمون خودکار:** ندارد (فقط صفحهٔ ایستا)

## نمای کلی

این صفحه دو کار می‌کند: خودش یک نمونه‌کار است و در همان حال، فهرست ورودی به نه پروژهٔ دیگر.

ترتیب بخش‌ها بر پایهٔ این فرض چیده شده که بازدیدکننده پیش از هر چیز باید بداند اینجا چه ساخته شده و بعد بفهمد چطور ساخته شده:

| بخش | توضیح |
|---|---|
| سرصفحه | عنوان اصلی، شمار پروژه‌ها و مسیرهای ورود |
| از مسئله تا راهکار | فرایند چهارمرحله‌ای: مسئله، راهکار، توسعه، محصول |
| پروژه‌های منتخب | سه نمونه با تصویر چسبان و جزئیات کامل |
| پروژه‌های بیشتر | هفت پروژه، دو کارت در هر ردیف، همراه با مسئله و راهکار هرکدام |
| توانمندی‌ها | چهار حوزهٔ تخصص با توضیح یک‌خطی |
| پشتهٔ فنی | فهرست تایپوگرافیک تکنولوژی‌ها |
| فرایند همکاری | چهار مرحله: درک، طراحی، توسعه، تحویل |
| درباره | توضیح کوتاه رویکرد |
| فراخوان پایانی | دعوت به مرور پروژه‌ها |

## قابلیت‌ها

- **ناوبری چسبان** با نوار پیشرفت اسکرول و منوی موبایل با پشتیبانی `aria-expanded`
- **ظاهرشدن تدریجی بخش‌ها** با `IntersectionObserver` و تأخیر پله‌ای
- **کارت‌های پروژه در دو ستون** تا تصویر اسکرین‌شات خوانا بماند
- **یادداشت شفافیت داده** روی پروژه‌هایی که مجموعهٔ دادهٔ نمونه دارند
- **تصاویر واکنش‌گرا** با `width`/`height` صریح برای جلوگیری از جابه‌جایی چیدمان
- **احترام به `prefers-reduced-motion`** — در این حالت هیچ محتوایی پنهان نمی‌ماند

## اجرای محلی

هیچ وابستگی و هیچ مرحلهٔ نصبی لازم نیست.

```bash
cd 01-portfolio-hub
python -m http.server 8000
# سپس در مرورگر: http://localhost:8000
```

بازکردن مستقیم فایل `index.html` هم کار می‌کند، چون همهٔ مسیرها نسبی‌اند.

## استقرار روی Render

مخزن چندپروژه‌ای است؛ **تعیین `rootDir` اجباری است**، وگرنه Render از ریشهٔ مخزن منتشر می‌کند و هیچ فایلی پیدا نمی‌کند.

### روش ۱ — Blueprint (پیشنهادی)

1. **New +** → **Blueprint**
2. مخزن `Demos-FA` را انتخاب کنید.
3. **Blueprint Path** را روی `01-portfolio-hub/render.yaml` بگذارید.
4. **Apply**.

### روش ۲ — Static Site دستی

| فیلد | مقدار |
|---|---|
| **Root Directory** | `01-portfolio-hub` |
| **Build Command** | خالی |
| **Publish Directory** | `.` |

`render.yaml` برای مسیرهای `/assets/*` کش بلندمدت و برای `index.html` بازبینی اجباری تعیین کرده است.

## دسترس‌پذیری

- ساختار معنایی: `header`، `nav`، `main`، `section`، `article`، `footer`
- پیوند «پرش به پروژه‌ها» به‌عنوان نخستین عنصر قابل فوکوس
- حالت فوکوس واضح با `:focus-visible`
- متن جانشین توصیفی برای همهٔ تصاویر
- ساختار سرفصل پیوسته: یک `h1` و `h2`های بخش‌ها

## کارایی

- بدون CDN، بدون فریم‌ورک، بدون کتابخانهٔ سمت‌کاربر
- فونت‌ها محلی و از نوع `woff2` با `font-display: swap`
- همهٔ تصاویر پایین صفحه `loading="lazy"` هستند
- انیمیشن‌ها فقط روی `transform` و `opacity` کار می‌کنند تا روی لایهٔ گرافیکی بمانند

## محدودیت‌ها

- آزمون خودکار ندارد؛ صحت با بازآزمایی دستی در مرورگر بررسی می‌شود.
- تصاویر پروژه‌ها اسکرین‌شات ثابت‌اند و خودکار به‌روز نمی‌شوند.
- صفحه اینترنتی وابستگی بیرونی ندارد، اما فونت Inter از Google Fonts بارگذاری می‌شود؛ برای کارکرد کامل بدون شبکه، باید محلی شود.
