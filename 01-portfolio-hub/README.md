# پورتفولیو هاب

نقطهٔ ورود واحد به مجموعهٔ پروژه‌ها: از وب‌سایت شرکتی و فروشگاه آنلاین تا ربات تلگرام،
داشبورد داده، عامل هوشمند، مدل یادگیری ماشین و پلتفرم گزارش‌سازی.

یک صفحهٔ تعاملی برای نمایش ده پروژه با تصویر واقعی هر برنامه، توضیح مسئله و راهکار،
پشتهٔ فنی و پیوند کد. ساخته شده با **HTML5، CSS3 و JavaScript خالص** — بدون فریم‌ورک
و بدون مرحلهٔ Build.

---

## ساختار صفحه

| بخش | توضیح |
|---|---|
| سرصفحه | عنوان اصلی، آمار، دکمه‌های هدایت |
| نوار اعتماد | چهار حوزهٔ تخصص با توضیح یک خطی |
| از مسئله تا راهکار | فرایند چهارمرحله‌ای解决问题 |
| پروژه‌های منتخب | سه کیس استادی با جزئیات کامل |
| پروژه‌های بیشتر | هفت پروژه در شبکهٔ کارتی |
| توانمندی‌ها | چهار بلوک编辑ی با برچسب فنی |
| پشتهٔ فنی | فهرست تایپوگرافیک تکنولوژی‌ها |
| فرایند همکاری | چهار مرحله: درک، طراحی، توسعه، تحویل |
| درباره | معرفی مختصر رویکرد |
| CTA نهایی | دعوت به مشاهدهٔ پروژه‌ها |

## فلسفهٔ طراحی

**آرامش فنی** (Quiet Technology): صفحه باید به‌خاطر فاصله‌گذاری، تایپوگرافی و ترکیب‌بندی
لوکس به نظر برسد، نه به‌خاطر افکت.

| مورد | مقدار |
|---|---|
| پس‌زمینه | `#0B0D0F` |
| سطح اولیه | `#111417` |
| سطح ثانویه | `#171B1F` |
| حاشیه | `rgba(255,255,255,0.08)` |
| متن اصلی | `#F3F1EC` |
| متن فرعی | `#A8AAA7` |
| متن کم‌رنگ | `#737875` |
| رنگ تأکیدی | `#8EAFC4` (آبی فولادی ملایم) |
| تایپ‌فیس فارسی | Vazirmatn — چهار وزن |
| تایپ‌فیس لاتین | Inter |
| تایپ‌فیس فنی | JetBrains Mono — دو وزن |

## اجرای محلی

```bash
cd 01-portfolio-hub
python -m http.server 8000
# سپس در مرورگر: http://localhost:8000
```

هیچ نصب یا مرحلهٔ Buildی لازم نیست. می‌توانید فایل `index.html` را مستقیم هم باز کنید.

## دپلوی روی Render

### راه اول — Blueprint (خودکار)

فایل `render.yaml` در همین پوشه، سرویس را کامل تعریف کرده است:

1. **New +** → **Blueprint**
2. مخزن `Demos-FA` را انتخاب کنید.
3. در صفحهٔ فیلدها، **Blueprint Path** را روی `01-portfolio-hub/render.yaml` بگذارید.
4. **Apply** — سرویس `portfolio-hub` ساخته و منتشر می‌شود.

### راه دوم — Static Site دستی

1. **New +** → **Static Site**
2. مخزن `Demos-FA` را انتخاب کنید.
3. **Root Directory**: `01-portfolio-hub`
4. **Build Command**: خالی بگذارید.
5. **Publish Directory**: `.`
6. **Create Static Site**

> نکتهٔ کلیدی: `rootDir` باید `01-portfolio-hub` باشد. مخزن چندپروژه‌ای است
> و بدون این تنظیم، Render از ریشهٔ مخزن منتشر می‌کند.

## استک

| لایه | فناوری |
|---|---|
| ساختار | HTML5 معنایی |
| استایل | CSS3 — Grid، Flexbox، `clamp()`، متغیرها |
| تعامل | JavaScript خالص — IntersectionObserver |
| فونت | وزیرمتن، Inter، جت‌برینز مونو (محلی) |
| تصاویر | JPEG بهینه در ۱۴۰۰×۸۷۵ |

بدون CDN، بدون کتابخانهٔ سمت‌کاربر، بدون درخواست شبکه‌ای به دامنهٔ سوم.

## دسترس‌پذیری

- ساختار معنایی (`header` / `nav` / `main` / `section` / `footer`)
- پرش به محتوا
- فوکوس واضح (`:focus-visible`)
- پشتیبانی از `prefers-reduced-motion`
- متن جانشین برای تمام تصاویر
- منوی موبایل با `aria-expanded`

---

## محدودیت‌ها

- لینک زنده فقط برای پروژه‌های هلدینگ آرمان و نافه فعال است.
- بعضی داده‌ها (خانه‌یاب و حس‌سنج) سینتتیک هستند.
- هیچ فرم تماس یا اطلاعات ارتباطی مستقیمی در صفحه نیست (عمدی).
- پیوند کد پروژهٔ ۰۱ تا پیش از انتشار خودِ این پوشه کار نمی‌کند.
